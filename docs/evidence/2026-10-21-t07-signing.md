# T-20261021-07 實測：寄件者驗證（信件 SSH 簽章＋senders 預設拒絕）（2026-10-21）

拓撲：指揮者（`~/.agent-relay`，信箱 `commander`）、收件端 machine-b（同一台主機的第二份 store clone，信箱 `claude-code`），兩邊透過 [Private Repo: 個人記憶庫] 的 `mailbox` 分支同步。簽章工具是 Windows 11 內建的 `C:\Windows\System32\OpenSSH\ssh-keygen.exe`。

## 1. 金鑰與信任

```text
指揮者    relay keygen  → ~/.agent-relay/keys/commander_ed25519
machine-b relay keygen  → <machine-b home>/keys/claude-code_ed25519
machine-b relay trust commander  <commander 公鑰>   → allowed_signers: commander namespaces="agent-relay" ssh-ed25519 …
指揮者    relay trust claude-code <machine-b 公鑰> → allowed_signers: claude-code namespaces="agent-relay" ssh-ed25519 …
```

machine-b 的 `dispatch` 沒設 `require_signature`，所以預設 `true`。`senders` 是 `["commander"]`。
